# Stable v1 transition

Stable v1.0 starts the long-lived Android application line under `io.github.raposomiguel50.systemshock` with a dedicated stable signing identity. The historical pre-release package `com.rp5np.systemshock` remains a separate development line and can coexist during transition.

This separation avoids making the first stable release depend on recovering the historical pre-release signing key. It does not change the preservation scope, game content or 1024x768 4:3 presentation.
