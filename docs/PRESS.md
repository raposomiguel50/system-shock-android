## 21 August 2026 — GenerationAmiga

**Publication:** GenerationAmiga.com  
**Article:** [System Shock Android port brings the 1994 classic to handhelds](https://www.generationamiga.com/2026/08/21/system-shock-android-port-brings-the-1994-classic-to-handhelds/)  
**Published:** 21 August 2026  
**Coverage type:** Independent editorial article

GenerationAmiga covered the first APK-bearing public pre-release of the project. The article describes the port as a native Android/ARM64 build based on Shockolate, with the Retroid Pocket 5 as the main reference device rather than a DOS-emulation setup.

The coverage specifically highlights:

- native Android / 64-bit ARM execution;
- the Retroid Pocket 5 as the current confirmed reference handheld;
- the preserved 1024x768 4:3 presentation without stretching;
- SDL GameController-based handheld controls;
- right-stick camera look and a separate fine cursor mode for the original interface;
- optional touchscreen interaction and Android text entry;
- the first-run importer for user-supplied compatible System Shock game data;
- the fact that commercial game data is not included in the APK;
- the pre-release status and the fact that broader Android-device compatibility is not yet established.

This represents the first recorded independent editorial coverage of this Android port.

## Record-keeping policy

External coverage is recorded here when it directly discusses this project or one of its public releases. Coverage is classified by source type — for example editorial article, independent video/news coverage, or community discussion — so different forms of attention are not conflated.

Inclusion records that the coverage exists; it does not imply endorsement by the publication, creator, community, the project, upstream Shockolate, or any System Shock rights holder.

Technical claims, release hashes, compatibility status and validation results remain authoritative only in the repository's release, build, verification and engineering documentation.
